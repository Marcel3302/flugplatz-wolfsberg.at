# Flugplatz Wolfsberg — Professional Website Demo V2

## Sofort ansehen
`index.html` doppelklicken. Der Admin-Prototyp liegt unter `admin-demo.html`.

## Bereits enthalten
- modernes responsive Premium-Design
- DE/EN Umschaltung
- Flugschule
- Pilot Briefing
- Betriebszeiten
- Demo-Wettermodul (Open-Meteo; ausdrücklich kein Aviation Weather)
- Flottenbereich
- News & Events
- Restaurant
- Kontaktformular-Demo
- Admin-Dashboard-Prototyp
- Mobile Navigation
- Verkaufs-/Übergabeunterlagen

## Vor einem echten Livegang
- schriftliche Freigabe/Rechte für Bilder, Logos und Inhalte vom KLV einholen
- operative Flugplatzdaten gegen aktuelle offizielle Luftfahrtpublikationen prüfen
- rechtsgültiges Impressum und Datenschutz ergänzen
- Kontaktformular serverseitig anbinden
- News/CMS/Admin mit Authentifizierung und Datenbank umsetzen
- falls gewünscht: Webcam-Quellen, Aviation-METAR/TAF-Quelle und PPR-Workflow integrieren
- Bilddateien lokal / über kundeneigenes CDN hosten, statt die Demo-URLs der bestehenden Website direkt einzubinden

## Empfohlener Live-Stack
- Frontend: statisch oder Next.js/Astro
- Hosting: Cloudflare Pages
- Git: GitHub Repository
- Backend: Cloudflare Workers + D1 oder Supabase
- E-Mail: Resend
- CMS: Decap CMS / Directus / Sanity oder eigenes schlankes Dashboard
- Analytics: Cloudflare Web Analytics
